Operation Guide

  1. Choose a bias mode in the sidebar: Voltage Divider, Fixed Bias, or Emitter Bias.
  2. Edit the circuit parameters and choose Run Simulation to compute the analytical Q-point.
  3. Set the signal source amplitude and frequency, then run SPICE simulation in the Results panel.
  4. Compare SPICE DC, AC, and transient results with the analytical reference. Values may differ because SPICE uses a transistor model.
